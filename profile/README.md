## What is Lumose?

Lumose (formerly GlycemicGPT) plugs into your CGM, your pump, Nightscout and the apps you already run, then turns that data into answers and daily briefs. It runs on your server, with the AI you choose.

- **Self-hosted.** Run it on a laptop, a home server or a VPS. Your data lives on infrastructure you control.
- **Privacy-first, no telemetry.** The platform doesn't phone home or collect usage data.
- **Bring your own AI.** Use an AI subscription you already have, or your own API key. Lumose doesn't host or resell AI. You can also run fully local with Ollama or any OpenAI-compatible endpoint. With a hosted provider, your question and health data go to that provider under its terms. With a local model, they stay on your network.
- **Daily briefs and AI chat.** Briefs show the numbers behind them, and you can ask questions about your glucose data.
- **Your phone, your wrist, the web.** A web dashboard, an Android app and a Wear OS watch face.
- **Read-only.** Every device connection only reads data.

**Alerts are in development.** Alerting is in active development and works only for some setups. Keep your CGM's own alerts on. Alerts are generated by fixed rules you can read in the code, and no language model decides, words, or sends an alert.

## Devices

If something hasn't been tested on real hardware, we say so.

| Device | Connection | Status |
|--------|------------|--------|
| Tandem t:slim X2 | Bluetooth (Android app) | Supported |
| Tandem Mobi | Bluetooth (Android app) | Untested |
| Medtronic 780G | Bluetooth (Android app), read-only | Beta |
| Medtronic 680G / 770G | Bluetooth (Android app) | Untested |
| Dexcom G7 | Cloud | Supported |
| Dexcom G6 | Cloud | Beta |
| Dexcom ONE+ | Cloud | Untested |
| Tandem cloud | Cloud | Supported |
| Medtronic CareLink (US) | Cloud | Beta |
| Medtronic CareLink (EU) | Cloud | Not working |
| Glooko: smart pens | Cloud | Supported |
| Glooko: Omnipod 5 | Cloud | Untested |
| Nightscout (Loop, AAPS, Trio, xDrip+, Libre and Eversense uploads) | Bridge | Supported |

**Beta:** built, not fully checked against real hardware. **Untested:** no real-hardware testing yet. **Not working:** [tracked on GitHub](https://github.com/lumose-health/lumose/issues/811).

Product names belong to their owners. Lumose is not affiliated with or endorsed by them.
